# Agent 面试评分卡

| 维度 | 权重 | 评分标准 |
|---|---:|---|
| 架构设计 | 30 | 是否有清晰 Agent loop、工具边界、记忆边界、终止条件 |
| 任务成功率 | 30 | eval 任务成功率、反问准确率、状态提交正确性 |
| 代码质量 | 20 | 小模块、类型清晰、错误处理集中、无无关重构 |
| 执行效率 | 10 | 平均步数、工具调用次数、耗时、token 控制 |
| 可观测性 | 10 | trace 完整度、日志、指标、失败可诊断性 |

## 加分项

- 能解释为什么固定 RAG pipeline 不是 Agent loop。
- 能指出非法 JSON、循环调用、工具失败的风险。
- 能提出多 Agent 扩展方案。
- 能把用户反馈转化为 eval 数据。
