# KnowFlow 用户手册

## 什么是 KnowFlow？

KnowFlow 是企业内部知识库 RAG（检索增强生成）问答系统。上传文档后，你可以用自然语言提问，系统会基于文档内容给出带来源引用的回答。

## 快速上手

### 1. 登录注册

访问 `http://localhost:3000`，首次使用先注册账号。

### 2. 上传文档

进入 **文档管理** 页面：
- 点击 "上传文档" 按钮选择文件
- 或直接拖拽文件到页面中央区域
- 支持格式：TXT / Markdown / PDF / DOCX / XLSX
- 上传后系统自动分块和向量化（状态变为"已索引"即可提问）

### 3. 开始提问

- 点击侧边栏 "+ 新对话"
- 输入问题，例如："公司的考勤制度是什么？"
- LLM 会基于检索到的文档内容流式生成回答

## 核心功能

### 知识库管理

支持创建多个知识库（如"研发文档"、"HR 制度"），文档和对话都可按知识库隔离。

- **文档管理页：** 顶部下拉选择当前知识库，上传文档自动归属
- **对话页：** 侧边栏选择知识库，仅搜索该库内容

### 对话功能

- **流式输出：** 回答逐字生成，实时可见
- **停止生成：** 对话进行中点击"停止生成"即刻中断
- **引用来源：** 回答底部显示匹配的文档块，点击可查看原文并高亮匹配段落
- **自动标题：** 首次对话后自动生成 4-6 字标题
- **重命名：** 侧边栏双击对话标题可手动修改
- **导出：** 鼠标悬停对话，可导出 Markdown 或 JSON 格式
- **搜索：** 侧边栏顶部搜索框可快速过滤历史对话
- **赞/踩：** 每条回答底部 👍👎 按钮，用于反馈回答质量

### 文档管理

- **预览：** 点击文档标题查看内容（PDF 内嵌预览，Markdown 渲染格式）
- **搜索：** 按标题过滤文档
- **排序：** 按最新/名称/状态排序
- **批量操作：** 勾选多个文档，批量删除或重新索引
- **拖拽上传：** 支持拖拽上传和点击上传两种方式

### 管理后台

管理员（角色为 admin）可见 **管理后台** 入口，功能包括：

**用户管理：** 查看用户列表，修改角色，启用/禁用账号
**权限管理：** 为每个文档单独授权指定用户
**数据统计：** 查看系统运行数据（用户数/文档数/检索命中率/满意度等）

### Prompt 模板

管理员可创建多个 Prompt 场景模板（通用问答/技术问答/HR 政策），对话时选择使用。

## 常见问题

**Q: 文档上传后状态一直是"处理中"？**
A: 检查 Worker 日志：`docker compose logs worker`

**Q: 搜索不到已上传的文档内容？**
A: 新文档需要等索引完成。如索引完成仍搜不到，运行 tsvector 回填：`docker exec knowflow-backend-1 python -m scripts.backfill_tsvector`

**Q: 如何启用 reranker（精排）？**
```bash
docker compose exec backend pip install FlagEmbedding
# .env 添加 RERANKER_ENABLED=true
docker compose restart backend
```

**Q: 限流了怎么办？**
A: 认证接口每分钟 5 次，对话接口每分钟 15 次，上传接口每小时 30 次。等待窗口过期即可。

## API 概览

| 端点 | 说明 |
|------|------|
| `POST /api/v1/auth/login` | 登录 |
| `POST /api/v1/chat/conversations/{id}/messages` | 发送消息（SSE 流） |
| `POST /api/v1/documents/upload` | 上传文档 |
| `GET /api/v1/documents/{id}/file` | 下载原始文件 |
| `GET /api/v1/knowledge-bases/` | 知识库列表 |
| `GET /api/v1/admin/stats` | 数据统计（需 admin） |
| `GET /api/v1/audit/logs` | 审计日志（需 admin） |
